# YouTrack Time Tracker для macOS — техническое задание

Приложение в строке меню macOS для учёта рабочего времени по задачам YouTrack. Пользователь утром составляет план из задач, в течение дня переключается между ними одним кликом или клавишей, а время сразу списывается в YouTrack как work items.

Рядом лежит `prototype.html` — интерактивный HTML-прототип, согласованный с заказчиком. Откройте его в браузере: он показывает поведение, тексты интерфейса и порядок экранов. Если ТЗ и прототип расходятся, приоритет у ТЗ. Визуальный стиль прототипа — только ориентир: в приложении нужен нативный вид macOS.

## Что в прототипе не переносить

Прототип — имитация в браузере. Часть элементов нужна только для демонстрации, в приложении их быть не должно:

- **Обвязка вокруг «экрана»:** заголовок страницы, строка шагов сценария («Включили Mac → … → Итог дня») с подсказками, блок пояснений под экраном.
- **«Панель прототипа»:** часы, кнопка «Ускорение ×60», «Отойти от компьютера на 20 мин», «Начать день заново». В приложении время реальное, простой определяется детектором активности, а новый день наступает по календарю.
- **Имитация macOS:** обои, строка меню с «Finder / Файл / Правка / Вид», дата и часы в строке меню, «светофор» в заголовках окон. Приложение отвечает только за свой значок в строке меню и свои окна, остальное рисует система.
- **Тестовые данные:** задачи `ATL-…`, `VEG-…`, `LYR-…`, `UST-…`, `SOP-…`, `ORG-…`, их названия, признак «в работе», вчерашний план, список проектов, адрес `youtrack.sellout.plus`. Всё это приходит из YouTrack и из сохранённого состояния.
- **Генерация ID новой задачи** (номер = максимум в проекте + 1). ID и проект выдаёт YouTrack в ответе на создание.
- **Мгновенные подтверждения «Списано / Изменено / Удалено / Создано в YouTrack».** В прототипе они появляются без запроса к серверу. В приложении показывайте их только после успешного ответа, а при ошибке — сообщение и запись в очереди отправки.
- **Задача `ORG-3` по умолчанию** в окне «Вы вернулись». В приложении по умолчанию предлагается задача, на которую в прошлый раз списывали простой, иначе первая задача плана.
- **Ограничение «одно окно за раз»** и подсказка «Сначала закройте окно». Это упрощение прототипа: в приложении окна независимы, а карточки списания живут отдельно от окон.
- **Вид поиска в меню** (поле прямо внутри выпадающего меню) показывает поведение, а не обязательную вёрстку. Допустимо сделать поиск отдельной всплывающей панелью, если это удобнее в SwiftUI, с тем же поведением клавиш.

Всё остальное — тексты интерфейса, порядок экранов, состав меню, поведение карточек, правила учёта — переносится так, как описано в разделах ниже.

## Платформа и стек

- **macOS 26 Tahoe** — минимальная и целевая версия.
- **Swift 6 и SwiftUI.** Точка входа — `MenuBarExtra` со стилем `.window`. Отдельные окна (настройки, «Доброе утро», списания и т. д.) делаются как SwiftUI-сцены `Window` или через `NSWindow`/`NSPanel`, где нужен особый режим.
- **Внешний вид — нативный Tahoe (Liquid Glass).** Используйте системные материалы и контролы, а не самописные. Поддержка светлой и тёмной темы обязательна.
- **Без иконки в Dock:** `LSUIElement = YES`.
- **Автозапуск при входе в систему** через `SMAppService.mainApp`, включается в настройках.
- **Язык интерфейса — русский.** Все строки выносите в String Catalog (`Localizable.xcstrings`).
- **Зависимости — минимум.** Глобальное сочетание клавиш можно сделать через библиотеку `KeyboardShortcuts` (sindresorhus) или через Carbon `RegisterEventHotKey`. Второй вариант не требует разрешения на универсальный доступ.

## Термины

- **Задача** — issue YouTrack, идентифицируется `idReadable` (например, `ATL-1482`).
- **План на день** — упорядоченный список задач, между которыми пользователь переключается сегодня. До 9 первых задач получают быстрые клавиши 1–9.
- **Отрезок** — непрерывный интервал учёта по одной задаче: задача, начало, конец.
- **Списание** — work item в YouTrack, созданный из отрезка.
- **Тип работы** — одно из значений: Разработка, Анализ, Созвон, Тестирование, Документация. Тип не отдельное поле, а приставка в начале комментария списания: `Анализ: разобрал замечания`.

## Состояния приложения

- **День не начат.** Учёт не идёт, в строке меню текст «Начать день».
- **Учёт идёт.** Есть текущая задача и время начала отрезка.
- **Пауза.** Пользователь остановил учёт вручную.
- **Учёт не идёт.** День начат, но текущей задачи нет (например, нажали «Начну позже»).
- **День завершён.** После «Завершить рабочий день». Дальше снова доступно «Начать рабочий день».

Одновременно идёт не больше одного отрезка.

## Строка меню

- Значок приложения (часы) и рядом текст.
- **Текст при идущем учёте** — только ID текущей задачи (`ATL-1482`). Настройка позволяет показывать «ID и начало названия», примерно 16 символов с многоточием.
- **Текст без учёта:** «Начать день» (день не начат или завершён), «Пауза», «Начать работу» (день начат, учёт не идёт).
- **Подсказка при наведении** — `ID — полное название`.
- **Индикатор состояния:** зелёный — учёт идёт, жёлтый — пауза, серый — не идёт.

## Выпадающее меню

Порядок блоков сверху вниз:

- **Шапка.**
  - Если учёт идёт: ID, полное название, таймер текущего отрезка (`ч:мм`), строка «Идёт учёт с 10:42 · к списанию 0:45» (сумма к списанию с учётом округления).
  - Если день не начат или завершён: крупная кнопка «Начать рабочий день» (↵).
  - Если день начат, но учёт не идёт: крупная кнопка «Начать работу» или «Продолжить работу» (на паузе) с подписью, какая задача запустится. Это последняя активная задача, если она есть в плане, иначе первая задача плана. Под кнопкой: «Или выберите другую задачу в списке ниже».
  - Если план пуст: кнопка «Составить план на день».
- **«Задачи на сегодня».** Каждая строка: отметка текущей, название, `ID · проект`, сколько времени по задаче сегодня (списано плюс идущий отрезок), клавиша 1–9. Клик останавливает текущий отрезок и запускает эту задачу.
- **Поиск.** «Другая задача из YouTrack…» (⌘F) раскрывается в поле поиска прямо в меню. Ищет по всем проектам по ID и тексту. Клик по результату добавляет задачу в план и запускает учёт. ↵ берёт первый результат. Под результатами, если поле не пустое, есть строка «Создать «…» в YouTrack».
- **«Новая задача в YouTrack…»** (⌘N), подпись «если позвали на то, чего ещё нет».
- **Пока идёт учёт:** «Пауза» (пробел) и «Я забыл переключиться…».
- **«Завершить рабочий день»** — пока учёт идёт или на паузе.
- **«План на день…», «Списания за сегодня…», «Настройки…» (⌘,).**
- **Подвал:** «Сегодня списано: ч:мм» и подсказка сочетания для открытия меню.

### Клавиатура

- **Глобальное сочетание** открывает и закрывает меню из любого приложения. По умолчанию ⌥⇧T, меняется в настройках.
- **Внутри открытого меню** (когда фокус не в поле ввода):
  - 1–9 — переключиться на задачу плана;
  - ↵ — «Начать рабочий день» или «Начать работу», в зависимости от состояния;
  - пробел — пауза;
  - любая буква — открыть поиск, и эта буква становится первым символом запроса;
  - ⌘F — поиск, ⌘N — новая задача, Esc — закрыть меню (или выйти из поиска).

## Начало дня

- Пункт «Начать рабочий день» открывает окно «Доброе утро».
- Окно может появляться само в заданное время. По умолчанию это **выключено**, включается в настройках.
- **Окно «Доброе утро»**, заголовок «Что берём в план на сегодня?». Два списка с чекбоксами, все отмечены по умолчанию:
  - «Вчера в плане» — план последнего рабочего дня (не обязательно вчерашнего календарного: после выходных это пятница);
  - «В работе у вас в YouTrack» — задачи по запросу из настроек (по умолчанию `for: me State: {In Progress}`), без дублей с первым списком.
- **Кнопки:**
  - «Взять выбранные» — план = отмеченные задачи, сразу переход к окну «Начало работы». Промежуточного окна плана нет.
  - «Собрать с нуля» — пустой план, открывается «План на день», после «Готово, дальше» — окно «Начало работы».
- **Окно «Начало работы»**, заголовок «С какой задачи начинаете?». Список задач плана, клик запускает учёт с текущей минуты. Внизу:
  - «Дополнить план…» — открывает «План на день», после него возврат сюда;
  - «Начну позже» — закрывает окно, учёт не идёт.
- **Окно «План на день»:**
  - список задач плана с кнопкой удаления у каждой;
  - строка подсказок «В работе у вас в YouTrack:» — кнопки `+ ID` для задач «в работе», которых ещё нет в плане;
  - поле поиска по YouTrack. **Результаты не показываются, пока поле пустое.** Клик по результату добавляет задачу, поле очищается. Под результатами есть «Создать «…» в YouTrack».

## Переключение и списание

### Правила отрезка

- Клик по задаче, клавиша 1–9, выбор из поиска или создание задачи заканчивают текущий отрезок и сразу начинают новый с той же минуты.
- Длительность отрезка — `конец − начало` в минутах.
- **Короткие отрезки.** Если длительность меньше порога (по умолчанию 2 мин), отрезок не списывается. Пользователь видит короткое уведомление «Не списано: ATL-1482 · 1 мин, это короче 2 мин».
- **Округление.** Если включено (по умолчанию да), каждое списание округляется **вверх** до 5 минут: `ceil(мин / 5) * 5`. Если выключено — до целой минуты.

### Уведомление со списанием

Это не системное уведомление, а собственная плавающая карточка. Она не перехватывает фокус и не блокирует работу. Рекомендуемая реализация — неактивирующийся `NSPanel` в правом верхнем углу экрана под строкой меню. Несколько карточек складываются стопкой.

Содержимое карточки:

- ID задачи, сумма к списанию (округлённая) и «факт ч:мм», обрезанное название;
- переключатель типа работы: пять кнопок. Выбранным по умолчанию становится последний тип по этой задаче, иначе тип по умолчанию из настроек;
- поле комментария, предзаполненное приставкой `Тип: `. Выбор другого типа меняет только приставку, остальной текст сохраняется;
- кнопки «Не списывать» и «Списать»;
- полоса обратного отсчёта и текст «спишется через N с».

Поведение:

- Через N секунд (по умолчанию 15) карточка сама отправляет списание.
- Фокус в поле, ввод текста или смена типа останавливают отсчёт. Текст меняется на «ждёт вас», дальше карточка ждёт решения пользователя.
- ↵ в поле — списать, Esc — не списывать.
- Если пользователь ничего не дописал, комментарий — просто тип (`Анализ`). Двоеточие в конце обрезается.
- После отправки показывается короткое подтверждение «Списано в YouTrack: ATL-1482 · 0:45 · «Анализ: …»».
- Настройкой карточку можно отключить: тогда списание уходит сразу с комментарием, равным типу.

### Пауза и завершение дня

- **«Пауза»** заканчивает отрезок (с уведомлением). «Продолжить работу» запускает последнюю задачу.
- **«Завершить рабочий день»** заканчивает отрезок, переводит день в «завершён» и открывает окно «Итог дня» — тот же список, что «Списания за сегодня». Окно обновляется, пока висят карточки списания.

## Простой (автопауза)

- Активность пользователя определяется по времени с последнего ввода: `CGEventSource.secondsSinceLastEventType(.combinedSessionState, eventType: CGEventType(rawValue: ~0)!)` (это `kCGAnyInputEventType`, любой ввод). Сон Mac и блокировка экрана тоже считаются простоем: `NSWorkspace.willSleepNotification` и `screensDidSleepNotification`, `com.apple.screenIsLocked` и `com.apple.screenIsUnlocked` через `DistributedNotificationCenter`.
- Если учёт идёт и простой превысил порог (по умолчанию 5 мин, настраивается, можно выключить), начало простоя — момент последней активности.
- **При возвращении** открывается окно «Вы вернулись», заголовок «Вас не было N минут» и строка «С 11:05 до 11:25 компьютер не использовался». Варианты:
  - **«Засчитать в другую задачу»** (выбран по умолчанию), с выбором задачи. Подсказка: «Например, были на созвоне без компьютера». Текущий отрезок заканчивается в начале простоя. Время простоя списывается на выбранную задачу через обычную карточку, тип по умолчанию «Созвон».
  - **«Засчитать в текущую»** — ничего не меняется, отрезок продолжается.
  - **«Отбросить»** — отрезок заканчивается в начале простоя, время простоя не списывается.
  - Чекбокс «Продолжить учёт по ATL-1482», отмечен по умолчанию. Если он отмечен, после применения новый отрезок по текущей задаче начинается с момента возвращения. Если нет — состояние «Пауза».
- Если учёт не шёл, окно не показывается.

## Забытый старт

- Если учёт не идёт (день не начат, пауза или «Начну позже»), а пользователь активно работает за компьютером дольше порога (по умолчанию 10 мин), показывается карточка-напоминание в том же стеке, что и уведомления списания, с выделенной рамкой.
- Время «без учёта» отсчитывается с конца последнего отрезка (или с начала дня). При простое отсчёт сбрасывается.
- Текст зависит от состояния: «Вы работаете уже N мин без учёта. Начать ATL-1482?», «Учёт на паузе уже N мин…», «…а рабочий день не начат».
- Кнопки:
  - если день не начат — «Начать рабочий день»;
  - иначе «С этой минуты» и «Начать с 10:20» (задним числом, с момента, когда учёт остановился);
  - всегда — «Через 30 мин» (отложить напоминание).
- Напоминание не показывается после «Завершить рабочий день» и пока открыто модальное окно. Карточка исчезает сама, как только учёт запущен любым способом.

## Исправление ошибок

### «Я забыл переключиться…»

Окно доступно, пока идёт учёт. Поля: «Последние, мин» (не больше длительности текущего отрезка, по умолчанию `min(15, длительность)`) и «На задачу». Применение:

- текущий отрезок заканчивается в момент `сейчас − N` (с обычной карточкой списания);
- по выбранной задаче начинается отрезок с момента `сейчас − N`, она становится текущей.

### «Списания за сегодня»

- Таблица записей за сегодня, новые сверху: время окончания, ID и комментарий, длительность, кнопка «Изменить».
- «Изменить» раскрывает строку: задача (выбор из всех задач), минуты, комментарий. Кнопки «Удалить», «Отмена», «Сохранить».
- Сохранение и удаление сразу меняют work item в YouTrack. Если поменялась задача, старый work item удаляется и создаётся новый на другой задаче.
- Внизу «Итого списано».

## Создание задачи в YouTrack

Сценарий: пользователя позвали на что-то, под что задачи ещё нет.

- **Точки входа:** пункт меню «Новая задача в YouTrack…» (⌘N), строка «Создать «запрос» в YouTrack» под результатами поиска в меню и в окне «План на день». Текст запроса подставляется в название.
- **Поля:**
  - «Название» — обязательно. Без него ошибка: «Введите название задачи, без него YouTrack её не создаст.»
  - «Проект» — по умолчанию последний проект, в котором создавали задачу, иначе проект текущей задачи.
  - «Описание» — необязательно.
  - «Назначить на меня» — по умолчанию включено.
  - «Сразу начать учёт» — по умолчанию включено при создании из меню и выключено из окна плана. Дополнительно поле «учёт с N мин назад», по умолчанию 0.
- **Результат:** задача создаётся в YouTrack и добавляется в план. Если выбран старт учёта, текущий отрезок заканчивается в момент `сейчас − N`, и по новой задаче начинается отрезок с того же момента. Подтверждение: «Создано в YouTrack: VEG-227 · Созвон по бонусам · на вас».
- Кнопка называется «Создать и начать» или «Создать», в зависимости от чекбокса. ↵ в поле названия — создать.

| Учёт времени | Показывать «Доброе утро» само в ЧЧ:ММ (вкл/выкл) | выкл, 09:30 |
| Списание | Округлять вверх до 5 минут | вкл |
| Списание | Не списывать отрезки короче N мин | 2 |
| Списание | Показывать уведомление и отправлять само через N с (вкл/выкл) | вкл, 15 |
| Списание | Тип работы по умолчанию | Анализ |
| Вид и клавиши | В строке меню: «Только ID» / «ID и начало названия» | Только ID |
| Вид и клавиши | Сочетание для открытия меню | ⌥⇧T |
| Система | Запускать при входе в систему | вкл |

Первый запуск без адреса или токена открывает настройки, раздел YouTrack, и проверяет подключение через `GET /api/users/me`.

## Интеграция с YouTrack

Авторизация: заголовок `Authorization: Bearer <permanent token>`, `Accept: application/json`, `Content-Type: application/json`. Используйте только параметр `fields`, чтобы не тянуть лишнее. Перед реализацией сверьте эндпоинты с версией YouTrack заказчика: ниже базовые пути из документации JetBrains.

| Действие | Запрос |
|---|---|
| Проверка подключения, текущий пользователь | `GET /api/users/me?fields=id,login,fullName` |
| Поиск задач (все проекты) | `GET /api/issues?query=<текст>&fields=id,idReadable,summary,project(id,name,shortName)&$top=20` |
| Задачи «в работе у меня» | то же с `query` из настроек |
| Список проектов | `GET /api/admin/projects?fields=id,name,shortName` |
| Создать задачу | `POST /api/issues` с `{"project":{"id":"…"},"summary":"…","description":"…"}` |
| Назначить на себя | `POST /api/commands` с `{"query":"for me","issues":[{"idReadable":"…"}]}` |
| Списать время | `POST /api/issues/{idReadable}/timeTracking/workItems` с `{"duration":{"minutes":45},"text":"Анализ: …","date":<мс UTC>}` |
| Изменить списание | `POST /api/issues/{id}/timeTracking/workItems/{workItemId}` |
| Удалить списание | `DELETE /api/issues/{id}/timeTracking/workItems/{workItemId}` |

Замечания:

- Поле `date` у work item — дата (полночь UTC в миллисекундах), без времени суток. Время начала и конца отрезка храните локально.
- Поле `type` work item не используется, тип работы живёт в тексте. Если позже понадобится маппинг на типы YouTrack, предусмотрите место в модели.
- **Очередь отправки.** Если YouTrack недоступен, списание и правки складываются в локальную очередь и отправляются при восстановлении связи. Пользователь видит неотправленные записи в «Списаниях за сегодня» с отметкой «ждёт отправки». Записи не должны теряться при перезапуске приложения.
- Поиск в меню — с задержкой (debounce) около 250 мс, последние результаты кэшируются.

## Хранение данных

Локально, в Application Support (SwiftData или JSON-файлы — на выбор разработчика):

- текущее состояние: текущая задача, начало отрезка, пауза, состояние дня — чтобы пережить перезапуск и сон;
- план на сегодня и план последнего рабочего дня;
- отрезки и списания за последние дни: локальный id, `workItemId` из YouTrack, задача, минуты (факт и к списанию), комментарий, время окончания, статус отправки;
- последний выбранный тип по каждой задаче;
- кэш задач: `idReadable`, `summary`, проект.

Настройки — `UserDefaults`, токен — Keychain.

## Граничные случаи

- **Перезапуск или сбой при идущем отрезке.** При запуске восстановить отрезок. Если с последней сохранённой активности прошло больше порога автопаузы, показать окно «Вы вернулись».
- **Полночь при идущем учёте.** Отрезок делится на два по границе суток, каждый списывается своей датой.
- **Повторный клик по текущей задаче** ничего не делает.
- **Задача удалена или стала недоступна в YouTrack.** Ошибка в уведомлении, запись остаётся в очереди с понятным текстом: что случилось и что сделать (выбрать другую задачу через «Изменить»).
- **Сон Mac** считается простоем, с тем же окном при возвращении.

## Критерии приёмки

- Приложение не показывает иконку в Dock. В строке меню при идущем учёте видна только ID задачи.
- При запуске окно «Доброе утро» не появляется само, пока это не включено в настройках.
- «Взять выбранные» сразу ведёт к «С какой задачи начинаете?», без окна плана.
- В «Плане на день» результаты поиска не видны, пока поле пустое.
- Переключение задачи никогда не открывает модальное окно. Карточка списания отправляется сама через 15 с, если её не трогать.
- Ввод текста в карточке останавливает отсчёт. Смена типа меняет только приставку комментария.
- Отрезок 1 мин при пороге 2 мин не создаёт work item. Отрезок 42 мин при включённом округлении списывается как 45 мин.
- После 10 мин работы без учёта появляется напоминание о забытом старте. «Начать с ЧЧ:ММ» начинает отрезок задним числом.
- «Я забыл переключиться» с N = 20 даёт два корректных отрезка, граница — `сейчас − 20 мин`.
- Правка и удаление в «Списаниях за сегодня» отражаются в YouTrack.
- Созданная задача появляется в YouTrack с назначением на пользователя, попадает в план и (если выбрано) становится текущей.
- Глобальное сочетание открывает меню поверх любого приложения. 1–9, ↵, пробел и буквы работают внутри меню.
- Без сети списания не теряются и уходят после восстановления связи.

## Порядок работ

- **Каркас.** Приложение в строке меню, состояния, таймер, план на день, переключение задач, локальное хранение. YouTrack на этом этапе — мок с данными из прототипа.
- **YouTrack.** Настройки подключения, Keychain, поиск, «в работе у меня», списание work items, очередь отправки.
- **Карточка списания.** Неактивирующаяся панель, отсчёт, тип в комментарии, короткие отрезки, округление.
- **Утро и конец дня.** «Доброе утро», «Начало работы», «Итог дня».
- **Простой и забытый старт.** Детектор активности, сон и блокировка, окно «Вы вернулись», напоминание.
- **Исправления и создание задач.** «Я забыл переключиться», правка и удаление списаний, создание задачи.
- **Клавиатура и полировка.** Глобальное сочетание, клавиши в меню, автозапуск, локализация, проверка по критериям приёмки.
